# Roadmap

A high-level view of where multilogin-labs is heading. Items are research-driven, not promises.

## Now (2026 Q2)

- [x] Homepage 100/100 PageSpeed (CLS < 0.1) — locked stack
- [x] Sitewide JSON-LD validator + a11y guardrails in CI
- [x] 22 indexable promo detail pages with per-vendor research
- [x] Open datasets manifest at `/data/index.json`
- [ ] May 2026 benchmark matrix (full release; preview is shipped)

## Next (2026 Q3)

- [ ] HowTo + Article schema audit on every guide page (top-3 rich result eligibility)
- [ ] Procurement evidence pack v2 — exportable PDF artifact
- [ ] Multi-region latency benchmark for cloud-phone use cases
- [ ] WebVitals telemetry beacon (opt-in, anonymous, sampled)

## Later (2026 Q4 +)

- [ ] Public methodology v1.3 with statistical confidence intervals
- [ ] Annual antidetect industry report (open data + commentary)
- [ ] Translated lab updates (RU, PT-BR, VI) for top reader geos
- [ ] Lightweight community submission flow for vendor reports

## Non-goals (won't do)

- Server-side rendering — site must remain a static GitHub Pages deploy
- Affiliate-only content with no methodology backing
- Mirroring vendor documentation (duplicate content risk)
- Display advertising

## How to influence the roadmap

- Vote on existing items: GitHub Discussions → Ideas category
- Propose new items: open a feature request issue
- Sponsor a benchmark month: open a Benchmark request discussion
